# 053 대시보드 가까운 순 기본값 및 마이페이지 구독 상태 필터

작성일: 2026-07-17

## 목적

대시보드의 수영장 목록은 전체 목록을 기본으로 보여주고 있어 실제 사용자가 가까운 시설을 먼저 찾기 어렵다.

또한 기존 `예정 / 시작 / 종료` 상태 구분은 수영장 목록에 있으면 의미가 어색하므로, 사용자가 실제로 상태별로 보고 싶은 `마이페이지 > 내 구독` 영역으로 옮기는 편이 자연스럽다.

## 변경 내용

### 1. 대시보드 수영장 목록

수정 파일:

```text
frontend/src/components/DashboardClient.tsx
```

변경:

- 대시보드 진입 시 브라우저 위치 권한을 사용할 수 있으면 `가까운 순` 목록을 자동으로 시도한다.
- 위치 권한이 거부되거나 위치 조회가 실패하면 기존 전체 목록을 그대로 유지한다.
- `가까운 순` 버튼은 현재 위치 기준 가까운 수영장 10개를 다시 조회한다.
- `전체 보기` 버튼을 항상 노출해 기존 전체 수영장 목록으로 돌아갈 수 있게 했다.
- 전체 목록으로 돌아가면 기존 페이지네이션 방식으로 전체 수영장을 볼 수 있다.

UX 기준:

```text
위치 권한 허용
-> 가까운 순 자동 표시

위치 권한 거부 또는 실패
-> 전체 보기 상태 유지
-> 사용자는 검색 또는 전체 목록을 그대로 사용할 수 있음
```

### 2. 마이페이지 구독 상태 필터

수정 파일:

```text
frontend/src/components/MyPageClient.tsx
```

변경:

- `내 구독` 섹션 안에 상태 필터를 추가했다.
- 필터는 `전체 / 예정 / 시작 / 종료`로 구성했다.
- 각 필터에 해당 구독 개수를 함께 표시한다.
- 기존의 `마감된 구독` 접힘 영역은 제거하고, `종료` 필터에서 바로 볼 수 있게 했다.
- 종료된 구독은 기존처럼 기간 수정은 막고, 구독 해제와 상세 확인은 가능하게 유지했다.

상태 의미:

| 필터 | 기준 |
|---|---|
| 전체 | 모든 구독 |
| 예정 | `event.status = UPCOMING` |
| 시작 | `event.status = OPEN` |
| 종료 | `event.status = CLOSED` |

## 판단

이번 변경 후 대시보드는 시설 탐색에 집중하고, 마이페이지는 사용자의 구독 상태 관리에 집중하게 된다.

```text
대시보드: 가까운 시설 찾기 / 전체 보기 / 공지 확인 / 구독 시작
마이페이지: 내 구독을 전체, 예정, 시작, 종료 상태별로 관리
```
