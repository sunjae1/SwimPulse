# 056 모바일 기준 위치 및 수영장 추가 후보 흐름 개선

작성일: 2026-07-19

## 목적

모바일 위치 검색이 초기 프론트엔드 구조에 머물러 장소 검색 후보와 시설 추가 요청의 역할이 섞여 있었다. 현재 웹 프론트엔드와 백엔드 API 명세를 기준으로 다음 두 역할을 분리했다.

1. 장소 검색 결과: 주변 탐색의 기준 위치 선택
2. 수영장 검색 후보: DB에 없는 시설의 추가 요청

## 기존 문제

- `/api/locations/search` 결과 카드에 `장소 정보`, `시설 추가 요청`이 함께 표시됐다.
- 장소 후보는 수영장이 아닐 수 있는데도 바로 시설 추가 요청 대상으로 사용할 수 있었다.
- 기준 위치를 선택한 뒤 `/api/pools/location-candidates`를 호출하지 않았다.
- DB에 이미 있는 가까운 수영장과 DB에 없는 외부 검색 후보를 구분해 보여주지 못했다.
- 선택한 위치가 수영장 목록 제목에 반영되지 않고 계속 `현재 위치 기준`으로 표시됐다.

## 최종 사용자 흐름

```text
장소 또는 주소 검색
-> /api/locations/search
-> 장소 후보 카드 선택
-> /api/locations/geocode
-> 두 요청 병렬 실행
   - /api/pools/nearby
   - /api/pools/location-candidates?radius=5000&query=체육센터&display=10
-> DB 수영장: 수영장 목록에 가까운 순으로 표시
-> DB 미등록 후보: 접이식 "수영장 후보" 영역에 표시
-> "이 시설 추가" 선택
-> 시설명·주소 확인
-> /api/pools/from-location-candidate 요청
```

## 구현 내용

### 기준 위치 후보

- 카드 전체를 누르면 기준 위치로 선택된다.
- `장소 정보`와 `시설 추가 요청` 버튼을 제거했다.
- 선택 중에는 다른 후보 입력을 막고 가까운 수영장 및 후보 조회 상태를 안내한다.
- 선택한 장소명은 `OO 기준 가까운 N개` 형태로 수영장 목록에 표시한다.
- 기본 화면의 옅은 하늘색 배경과 섞이지 않도록 검색 결과 패널은 흰색 본문, 파란 상단 강조선, 진한 blue header로 구분했다.
- 기준 위치 후보 카드는 아주 옅은 blue 톤으로 유지해, 실제 흰색 수영장 목록과 시각적으로 역할을 나눴다.

### DB 미등록 수영장 후보

- 위치 선택 후 `/api/pools/location-candidates`를 함께 호출한다.
- 응답 중 `alreadyExists=false`인 후보만 남긴다.
- 기본 상태는 접혀 있으며 `DB에 없는 수영장 후보 N곳`을 누르면 펼쳐진다.
- 후보에는 시설명, 주소, 카테고리, 기준 위치와의 거리를 표시한다.
- `이 시설 추가`를 누르면 Android 기본 Alert 대신 앱 스타일의 커스텀 확인 모달을 연다.
- 모달에서 시설명, 주소, 카테고리, 거리와 관리자 검토 안내를 다시 확인한다.
- `취소`는 모달만 닫고, `요청하기`를 눌렀을 때만 POST 요청을 전송한다.
- 요청 중에는 버튼과 Android 뒤로 가기 닫기를 막아 중복 전송을 방지한다.
- 요청 성공 후보는 현재 접이식 목록에서 제거한다.
- 비로그인 사용자가 추가 요청을 누르면 로그인 필요 안내를 표시한다.

## 웹과의 동작 일치

| 구분 | 웹 | 모바일 |
|---|---|---|
| 장소 검색 API | `/api/locations/search` | 동일 |
| 장소 선택 | 후보 행 클릭 | 후보 카드 전체 클릭 |
| 주소 좌표 변환 | `/api/locations/geocode` | 동일 |
| DB 수영장 조회 | `/api/pools/nearby` | 동일 |
| 외부 시설 후보 조회 | `/api/pools/location-candidates` | 동일 |
| DB 미등록 필터 | `!alreadyExists` | 동일 |
| 후보 표시 | 접이식 목록 | 접이식 목록 |
| 추가 요청 | 확인 모달 후 POST | 앱 스타일 확인 모달 후 POST |

## 수동 확인 항목

1. 위치 검색에 `수원` 또는 시설 주변 장소를 입력한다.
2. 장소 결과에는 기준 위치 선택 정보만 있고 홈페이지 및 시설 추가 버튼이 없는지 확인한다.
3. 후보 카드를 눌러 수영장 목록 제목이 선택 장소 기준으로 바뀌는지 확인한다.
4. DB 미등록 후보가 있을 때 접이식 수영장 후보 영역이 나타나는지 확인한다.
5. 접이식 영역을 펼쳐 거리와 `이 시설 추가` 버튼이 보이는지 확인한다.
6. 추가 요청 전 시설명과 주소 확인 창이 나타나는지 확인한다.
7. 요청 완료 후 해당 후보가 목록에서 제거되는지 확인한다.
